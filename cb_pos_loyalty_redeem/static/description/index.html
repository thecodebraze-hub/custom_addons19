POS Loyalty Redemption

Redeem any amount of loyalty points at the POS

Standard Odoo POS loyalty only supports fixed rewards. This module lets a cashier redeem any custom amount of a customer's loyalty points as a discount on the current order.

1. Enable in POS Settings

Enable Custom Loyalty Redemption, select the program, point value, and redemption product.

2. Open Redeem Points

On the order screen open Actions → tap Redeem Points.

3. Choose Points to Redeem

See available points, enter the amount (or Max), preview the discount, then Redeem.

4. Applied on the Order

A negative Loyalty Redemption line is added and the order total updates instantly.

5. Loyalty Card Balance

Customer loyalty card shows the live balance and history lines for issued / used points.

Key Features

Flexible Redemption

Enter the points to redeem, see the discount amount instantly (based on your configured point rate), and apply it as a negative order line.

Live Balance Check

Available points are fetched from the server when opening Redeem Points, so the cashier always sees the real card balance.

Safe Point Deduction

Points are deducted from the loyalty card only after the order is paid, with full loyalty history. Cancelled paid orders restore the points.

Per POS Settings

Enable per point of sale, choose the loyalty program and the point value rate.

Requirements

Requires Point of Sale and POS Loyalty (Odoo Enterprise loyalty).
