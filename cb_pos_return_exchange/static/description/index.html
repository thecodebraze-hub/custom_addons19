POS Return Exchange

Returns, exchanges & store-credit vouchers from POS

Give your retail team a professional return workflow without leaving the POS. Look up the original sale, return all or part of an order, issue vouchers, process exchanges, scan barcodes, print thermal receipts, update stock, post credit notes, and analyse return trends — fully integrated with Odoo 19 Point of Sale, Inventory, and Accounting.

Product Barcode → Exchange Voucher

Scan a product barcode (no receipt needed) to build an exchange voucher — ideal for gift / no-receipt exchanges.

1. Scan or type the barcode

Open Return / Exchange and enter the product barcode, then Search.

2. Confirm exchange product(s)

Review qty and voucher value, then tap Confirm to generate the voucher.

3. Return voucher issued

Voucher number, value, remaining balance, expiry, and customer are shown — Print or Done.

4. Printable exchange voucher

Thermal / PDF voucher with barcode for later redemption at payment.

POS Order Number → Return

Enter a POS order / receipt number to return selected lines, choose disposition and settlement, then print the return receipt and voucher.

1. Find the original order

Scan or type the receipt / order number — matching orders are listed with line summary.

2. Select lines & confirm return

Pick items and qty, set disposition (Restock / Scrap / Quarantine), settlement method, then Confirm Return.

3. Return receipt

Printed RETURN RECEIPT with return ID, original order, refund method, and voucher barcode.

4. Return voucher issued

Store-credit voucher is created with value, expiry, customer, and linked return reference.

Buy Another Item with Return Voucher

After a return, ring up a different product and apply the voucher at payment — remaining balance can be paid by cash or card.

1. Payment → Scan Voucher

On the payment screen tap Scan Voucher next to the customer.

2. Enter voucher barcode

Scan or type the voucher barcode, then Add Voucher.

3. Voucher applied on payment

Return Voucher reduces the total — remaining amount stays payable by Cash / Card.

4. Sale receipt with voucher

Final ticket shows new items, Return Voucher credit, and remaining cash/card paid.

Return & Exchange Settings

Configure refund window, voucher expiry, partial / multi-voucher usage, and printing options.

Voucher Report

Track issued, redeemed, and remaining voucher amounts with status and expiry dates.

Why retailers choose this module

Returns

Partial returns, refund methods, lot/serial tracking, and restock / quarantine / scrap disposition.

Vouchers

Issue store credit, print barcodes, redeem at payment — partial and multi-voucher supported.

Exchanges

Return items and sell replacements in one balanced settlement flow.

Backend integration

Inventory
Return pickings are created automatically with restock, quarantine, or scrap routing. Lot and serial numbers are validated against the original delivery.

Accounting
When the original POS order is invoiced, credit notes can be created and posted automatically according to your settings.

Thermal receipts
Print return, voucher, and exchange receipts in 58 mm or 80 mm PDF format — ready for thermal printers.

Audit trail
Every validation, redemption, print, and cancellation is logged for compliance and store manager review.

Reporting & access

Managers get reporting under Point of Sale → Reporting → Returns & Exchanges: dashboard KPIs, voucher/return pivots, Excel and PDF export.

Role-based permissions: Cashier, Manager, Administrator. Multi-company record rules included.

How to get started

  1. Install POS Return Exchange from Apps.
  2. Assign users to POS Return & Exchange → Cashier or Manager.
  3. Open Point of Sale → Configuration → Return & Exchange Settings.
  4. Review the Returns & Exchanges tab on each POS configuration.
  5. Open a POS session — use Return and Exchange on the product screen.
