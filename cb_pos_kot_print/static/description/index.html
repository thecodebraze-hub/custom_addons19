POS KOT Print

Print Kitchen Order Tickets directly from the Point of Sale

A dedicated KOT button and preview wizard for restaurants and bars. Print kitchen tickets on your 80mm receipt printer (Epson, IoT Box, or browser) without configuring separate Order Printers.

Key Features

Separate KOT button
Full-width KOT bar on the order screen shows pending kitchen items by category. The standard Send button stays unchanged for the normal kitchen flow.

Preview before printing
Click KOT to open a wizard on top of the current order screen. Review the ticket, then print or go back to the order.

Per-product control
Mark only the products that need a kitchen ticket with the KOT Product checkbox on the product form.

80mm thermal printer ready
Uses the same receipt printer pipeline as Odoo POS (Epson ePOS, IoT Box, or browser print fallback). Company name and KITCHEN ORDER header are printed on every ticket.

How It Works

  1. Enable KOT Printing in Point of Sale settings (Restaurant section).
  2. Tick KOT Product on kitchen items in the product catalog.
  3. Add items to a POS order — the KOT button appears when there are pending kitchen changes.
  4. Click KOT → preview the ticket in the wizard → click Print KOT.
  5. After printing, the order screen stays open and KOT tracking updates independently from Send.

Printer Setup

Configure your POS receipt printer as usual in Odoo settings:

  • Epson 80mm — enable Other Devices and set the Epson Printer IP.
  • IoT Box — connect the 80mm ESC/POS printer and set the IoT Box IP.
  • USB / browser — use the browser print dialog and select your 80mm printer.

Requirements

Requires Point of Sale, Restaurant, and Settle Due (pos_settle_due — Odoo Enterprise).
