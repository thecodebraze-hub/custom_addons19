Shopify Connector

Connect Odoo 19 with your Shopify stores

Production-ready foundation for synchronizing products, customers, orders, and inventory between Odoo and Shopify with secure credential management, queue processing, structured logging, and webhook support.

Core Capabilities

01

Store Management

Configure multiple Shopify stores per company with API credentials, connection status, and synchronization tracking.

02

Queue and Logs

Monitor asynchronous jobs and API activity with dedicated queue and log views designed for operational troubleshooting.

03

Service Architecture

Built on a clean service layer ready for OAuth, API integration, synchronization workflows, and webhook processing.
