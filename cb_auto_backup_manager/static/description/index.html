CB Auto Backup Manager

Automated PostgreSQL and filestore backups for Odoo 19 — Local, SFTP, and Google Drive

Schedule verified backups, deliver archives to multiple destinations, and test restores safely.

Why this module

CB Auto Backup Manager backs up PostgreSQL databases and Odoo filestores on the same server. Backup Administrators define plans, schedules, retention, destinations, and optional AES-256 encryption — without overwriting the live database.

  • Backup Plans with Backups Per Day and daily, weekly, or monthly times
  • Odoo-compatible ZIP archives (dump.sql + filestore) for Database Manager restore
  • Local Server, SFTP, and Google Drive — multiple destinations per plan
  • SHA-256 checksums, ZIP integrity checks, and optional AES-256-GCM encryption
  • Retention cleanup with audit logs and native Odoo notifications
  • Dashboard, backup verification, and temporary restore testing
  • Backup Administrator and Backup Operator security groups

Security and limitations

  • Secrets (SFTP, Google OAuth, encryption) visible only to Backup Administrators
  • No shell=True — PostgreSQL dumps use pg_dump safely
  • ZIP path traversal rejected; current database drop protection on restore tests
  • Does not overwrite live production, restart services, or provide incremental backups
  • Does not include AWS S3, Azure Blob, or Dropbox

Requirements: Odoo 19, PostgreSQL with pg_dump, Python paramiko for SFTP, Google Cloud OAuth client for Google Drive.
