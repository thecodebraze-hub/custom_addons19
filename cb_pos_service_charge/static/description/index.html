POS Service Charge

Add percentage-based service charge to POS orders with one click

A dedicated Service Charge option inside the POS Actions menu (⋮) opens a compact wizard where cashiers can review the order total, set the commission percentage (default 10%), preview the calculated charge, and apply it to the bill before payment.

Key Features

Actions menu + wizard
Open the ⋮ Actions menu and tap Service Charge to open the popup. No automatic charges — the cashier decides when to apply.

Editable commission %
Default rate is 10% and can be changed per order using the on-screen numpad before confirming.

Live preview
See the order total, calculated service charge amount, and final total in the wizard before clicking OK.

Bill & receipt ready
Service charge is added as an order line (e.g. Service Charge (10%)) and appears on the POS total, printed bill, and payment receipt.

How It Works

  1. Install the module and enable Service Charge in Point of Sale settings.
  2. Assign the default service charge record (10%) to your POS configuration.
  3. Add products to a POS order.
  4. Click ⋮ Actions → Service Charge → adjust the % if needed → OK.
  5. Print the bill or proceed to payment — the service charge line is included in the total.

Configuration

  • POS Settings — enable Service Charge and select the default rate configuration.
  • Service Charges menu — manage rate, product, and company under Point of Sale configuration.
  • Per order — use Remove in the wizard to clear service charge from the current order.
