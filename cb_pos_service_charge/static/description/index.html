POS Service Charge

Add percentage-based service charge to POS orders with one click

A dedicated Service Charge option inside the POS Actions menu (⋮) opens a compact wizard where cashiers can review the order total, set the commission percentage (default 10%), preview the calculated charge, and apply it to the bill before payment.

1. Open from Actions

Tap ⋮ Actions → % Service Charge on the POS order screen.

2. Set the percentage

Review order total, edit the % with the numpad, then confirm with OK.

3. Applied on the order

Service Charge (10%) appears as an order line and updates the total instantly.

4. Shown on the receipt

The printed receipt clearly shows Service Charge and the final total.

Key Features

Actions Menu

Open ⋮ Actions and tap % Service Charge. Cashiers choose when to apply — nothing is added automatically.

Editable Rate

Default is 10%. Change it per order with the numpad, or use + / − to nudge by 1%.

Live Preview

See order total, service charge amount, and final total before confirming.

Auto Recalculate

When products, quantities, prices, or discounts change, the service charge updates automatically. Printed receipts stay in sync.

How It Works

  1. Install the module and enable Service Charge in Point of Sale settings.
  2. Assign the default service charge record (10%) to your POS configuration.
  3. Add products to a POS order.
  4. Click ⋮ Actions → % Service Charge → adjust the % if needed → OK.
  5. Print the bill or proceed to payment — the service charge line is included in the total.

Configuration

  • POS Settings — enable Service Charge and select the default rate configuration.
  • Service Charges menu — manage rate, product, and company under Point of Sale configuration.
  • Per order — use Remove in the wizard to clear service charge from the current order.

Requirements

Requires Point of Sale and Restaurant. Compatible with Odoo Community and Odoo Enterprise.
