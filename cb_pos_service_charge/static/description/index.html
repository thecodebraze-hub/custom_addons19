POS Service Charge

Add a flexible percentage service charge to any POS order

Give cashiers a simple % Service Charge action in Point of Sale. Set or edit the rate per order, preview the calculated amount and final total, then show the charge clearly on the order and printed receipt.

Complete Service Charge Flow

01

Open from Actions

Open the POS Actions menu and select % Service Charge.

02

Set the Percentage

Enter a rate with the numpad and review the live calculation before applying it.

03

Charge and Print

The service charge updates the order total and appears on the customer receipt.

1. Available in POS Actions

Cashiers can access % Service Charge without leaving the active order.

2. Flexible Rate with Live Preview

View the order total, edit the commission percentage, and preview both the service charge amount and final total before confirming.

3. Included in the Order Total

The applied percentage and amount are clearly visible in the order summary.

4. Clear on the Printed Receipt

Customers receive an itemized bill showing the rate, charge amount, and final total.

Key Features

Percentage Based

Calculate the service charge from the current order total using an editable rate.

Automatic Recalculation

Keep the charge synchronized when products, quantities, prices, or discounts change.

Per-POS Configuration

Enable the feature and select the default service charge configuration per Point of Sale.

Live Total Preview

Review the charge and final payable total before changing the active order.

Easy Removal

Reopen the wizard to change the rate or remove the service charge from the order.

Receipt Ready

Display the service charge clearly in the POS order and printed customer receipt.

Quick Setup

  1. Install the module and open your Point of Sale settings.
  2. Enable Service Charge and choose the default configuration.
  3. Start a POS session and add products to an order.
  4. Open Actions, select % Service Charge, set the rate, and confirm.
